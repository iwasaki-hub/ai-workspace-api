# メニューバーの文字色改善（2026-11-16）

## 目的
メニューバーのリンク文字が薄いグレーで見えにくいため、既存のネイビー背景のまま、明確な白色へ変更する。

## 変更
- `public/css/style.css` の `.primary-nav>a` を `color: #fff` に変更。
- 文字の太さを `font-weight: 600` にして視認性を改善。
- Font Awesomeのメニューアイコンを `opacity: 1` にして文字と同じ明瞭さにする。
- PCとスマートフォンのどちらにも共通のCSSを適用。ハンバーガーメニュー、Motionアニメーション、ナビゲーションのリンク先などは変更しない。

## 検証
- 自動テストでCSSの文字色、アイコンの不透明度、モバイルメニューの既存動作を確認。
- 保護されたmainへのPR・Renderデプロイ・本番スモークテストを確認する。
- 実機での見た目の確認は別途実施する。
