# MotionによるUIアニメーション追加（2026-11-16）

## 目的

既存の静かなネイビー・ブルー・ミント配色とEJS構造を変えず、公開サイトに適度な動きを追加する。

## 使用パッケージ
- npm `motion@14.14.0` を依存パッケージに追加
- ブラウザ用配布ファイル `node_modules/motion/dist/motion.js` をExpressの `/motion-assets/motion.js` で配信する（CDN依存なし）
- アニメーション設定は `public/js/animations.js` に一元管理する
- フロントエンドのビルドツールやReact化は不要
- 以前の希望に従い、`package-lock.json` と `npm ci` への変更は行わない

## アニメーション

1. ファーストビュー：見出し・説明・ボタンを短く順番にフェードイン
2. コードプレビュー：自然に浮かぶような入場
3. 機能カード・Resources・エンドポイント・API操作画面・ロードマップ：スクロール時に一度だけフェードイン
4. カード・主要ボタン：ホバーできるPCでのみ、ごく小さい移動と拡大

## アクセシビリティ・品質

- OS/ブラウザの `prefers-reduced-motion: reduce` を尊重し、該当時はアニメーションを実行しない
- JavaScript未実行・Motionが取得できない場合も、元のHTMLはそのまま表示される
- タッチ操作環境にホバーアニメーションを適用しない
- レイアウトや文言、API、MongoDB、セキュリティ設定を変更しない
- Motionライブラリの取得・読み込み順・UI配信・動き低減時のフォールバックをテストする

## 検証

既存30ケースに追加3ケース。PR CIで成功後に保護された `main` へマージし、Renderの自動デプロイと本番APIのスモークテストを確認する。実ブラウザの視覚的な動き・iPhoneでの動作は別途目視確認する。
