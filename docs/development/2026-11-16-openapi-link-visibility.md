# OpenAPIリンク視認性の改善（2026-11-16）

## 背景
従来のEJSトップページ「API エンドポイント」のOpenAPI案内は、文章内にリンクが埋め込まれていたため、クリックできる場所が分かりにくいとのユーザーレビューを受けた。

## 変更点
- 説明文とリンクを分離し、`Swagger UIで見る` と `JSON仕様書を見る` の2つを明確なボタンとして表示。
- 主導線は青背景のSwagger UIボタン、補助導線は白背景で枠線のJSONボタンとして区別。
- 矢印・アイコンを添え、マウスホバーとキーボードフォーカスを明確化。
- 44px以上のタップ領域と狭い画面では縦並び・横幅いっぱいのボタンを使用。
- 元のURL (`/swagger`, `/openapi.json`) およびAPIの動作は変更なし。
- EJSとCSSのHTTP配信確認を回帰テストに追加。

## 検証
GitHub Actions `Node.js API Regression Tests` を通した後、保護されたmainへマージし、Renderのデプロイ状況と公開画面を確認する。実際のクリック操作・スマホでの視覚的確認は利用者側で追加確認する。
