# API仕様ページ：ブラウザ実行機能の追加（2026-11-16）

## 目的
ユーザーがAPI URLを手で組み立てなくても、公開ドキュメント上からGET APIを呼び出し、HTTPステータスとJSONを確認できるようにする。

## 実装内容
- `views/index.ejs` に「ブラウザでAPIを試す」セクションを追加
- `public/js/explorer.js` を追加。選択したパスへ同一オリジンのGETリクエストのみ送信
- エンドポイントの選択肢: 一覧、status絞り込み、ObjectId指定、health
- HTTPステータス・経過時間・整形したJSONを表示し、レスポンスのコピーも可能
- ObjectIdは24桁16進数のみ受け付ける
- 入力やHTTPレスポンスは`textContent`で表示し、HTMLとして解釈させない
- 書き込みHTTPメソッド・外部URLの入力欄は提供しない
- タイムアウト15秒、送信中は二重送信を防ぐ
- iPhone等の小さい画面では縦1列のレイアウトにする
- 既存のロードマップ文言を、接続・公開済みの実際の状況に更新

## 検証
- 既存のNode.js APIテスト13件に、ドキュメントの新UIとJSファイル配信を確認する2件を追加（合計15件）
- GitHub Actionsで成功後にmainへマージ
- Render自動デプロイと本番スモークテストを確認する
- **ブラウザ画面上のクリック・モバイル視覚確認は別途実施する**。CIではGUI操作を自動化していない

## 注意
`GET /health` はDBまでの正常性を証明しない。実際のMongoDB接続確認には`GET /api/users`を使用する。
API一覧には公開デモデータのみ表示されるようにサーバー側で制御している。UIの制御はアクセス権管理ではない。
