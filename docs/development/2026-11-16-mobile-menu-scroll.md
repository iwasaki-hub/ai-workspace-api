# モバイルのハンバーガーメニュー：スクロールで自動的に閉じる（2026-11-16）

## 背景
小さい画面でメニューを開いたままページをスクロールすると、メニューが画面上に残って操作の邪魔になるため、自然に閉じる動作を追加。

## 変更
- `public/js/main.js` のメニュー開閉を `setMenuOpen()` に統一。
- メニューを開いた瞬間のページスクロール位置を保存し、上下どちらかへ3pxを超えてスクロールしたら自動で閉じる。
- スクロールイベントは `passive: true` とし、画面スクロールを妨げない。
- 微小なスクロール位置の誤差（3px以内）は無視する。
- メニューの開閉ボタン、ナビゲーションのリンクを押したときの既存の動作も維持する。
- 閉じる際には `is-open` クラスと `aria-expanded`、`aria-label` を同時に更新し、表示とアクセシビリティの状態を一致させる。
- CSSやデザイン、Motionアニメーション、API側の動作には変更を加えない。

## 検証
- Node.jsのVMモックで開閉・微小スクロール・上下スクロール・再開時の基準位置・リンククリック・ARIA更新を自動テスト。
- 既存33件+新しい1件=34件の回帰テストをGitHub Actionsで実行。
- 成功後に保護されたmainへPRをマージし、Renderの公開環境とスモークテストを確認する。
- iPhone Safari等の実機スクロール動作は別途ブラウザ目視で確認する。
