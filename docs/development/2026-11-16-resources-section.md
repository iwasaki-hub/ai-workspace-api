# Resourcesセクション追加（2026-11-16）

## 目的
JSONPlaceholderの「Resources」のように公開リソースを見つけられるセクションを、既存デザインを維持したままトップページへ追加する。

## 実装
- 既存の機能紹介の直後、APIエンドポイント一覧の前に「利用できるリソース」を配置。
- 公開済みリソース **`/api/users` のみ**表示。未実装の `posts` / `comments` / `todos` は表示しない。
- リソース名はJSONへ遷移するリンク。外部URLではなく既存の公開GET APIへ接続。
- 件数は `/api/users` の公開GETレスポンス配列からブラウザ側で計算する。固定の3件とはしない。
- 取得エラー・429・503の場合は「取得できません」と表示し、架空の数値は使わない。現行APIは最大50件返却のため、50件時は「50件（上限）」と明示する。
- 表示対象は `ui/resources.js` で一元管理。新リソースの実装・検証後にレジストリへ追加可能。
- Font Awesomeは既存の `ui/icons.js` に `users` アイコンを登録して再利用。
- カラー、タイポグラフィ、余白、枠線は既存のデザイン変数を使用。小さい画面では折り返し表示。
- MongoDBテーブル、APIルート、レート制限、認証情報には変更を加えない。

## 注意
ホームページの件数取得は公開APIを1回呼び出すため、既存の120回/分のレート制限に含まれる。APIエンドポイントが増えたときは、件数の取得方法や負荷をあらためて検討する。公開一覧の表示件数は総レコード数とは異なる可能性がある。

## 確認
- GitHub Actionsで既存27件+新しい3件=30件の回帰テストを実行
- mainの保護ルールを維持してPR経由でマージ
- Renderのデプロイ状態と本番スモークテストを確認
- iPhoneなどでの見た目とクリック操作は別途手動確認
